Virtual platter (test mode)

Control source is set to Virtual platter: drag the record above with the mouse. The app synthesizes the same control tone the WOW plays and runs it through the real decoder.

WOW setup
  1. Download the control tone (right panel) and load it onto the WOW as a sample, the same way you load any scratch sample.
  2. Pilot-fader mode (recommended): put the pilot WAV in the WOW's beats folder, set fader_left = beat and fader_right = beat in wow_settings.txt, center the mix knob, keep delay/reverb off. Tone-level mode: balance fully to sample instead.
  3. WOW output → an input on your interface. Live audio (synth, mic, OP-1, anything) → another input. Pick both above.
  4. Motor on, hands off, fader open → press Calibrate. It measures 1× speed and the WOW's output level, so the WOW crossfader becomes LiveSkratch's fader.
  5. Scratch. Hands off and the needle rides at live. Pull back and you're scratching the last few seconds; let go and it snaps back to live, unless Return is set to Stay.
  6. Hit Freeze to capture a phrase and scratch it like a record. The tape stops recording and loops the last N seconds.

Routing

If your interface's direct monitoring blends the WOW tone into outputs 1–2, send LiveSkratch to another pair (e.g. 3–4) or another device.
